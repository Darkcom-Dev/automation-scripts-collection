# Texture Ops
Created for realize various operation over textures *.png for optimize videogames projects or 3D models.

>> Nota: remember give execution permissions to scripts for facilitate the execution.

- **channel_mixer.py:** join many grayscale texture files in each color channel to make one colored texture file.
- **atlas_builder.py:** join 4 colored textures into one texture.
- **psd_layer_splitter:** split all layers of PSD file in individual PNG texture files
- **swap_channels.py:** swap a color channel with other color channel.
- **psx_texture:** convert the normal image file to format compatible with psx
